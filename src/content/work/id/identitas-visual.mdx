## Konteks

Saya ingin punya bukti kerja identitas visual yang utuh, bukan hanya konten harian. Karena itu saya membuka proyek ini: merancang identitas visual penuh untuk sebuah usaha kecil, mulai dari brief sampai penerapan ke media sosial dan kemasan.

## Peran saya

Semua peran: menyusun brief, riset referensi, merancang logo, menetapkan sistem warna dan tipografi, lalu menerapkannya ke beberapa media.

## Batasan

- Belum ada klien nyata — proyek ini murni latihan berstandar kerja profesional dan akan saya beri label jelas sebagai proyek mandiri.
- Waktu pengerjaan dibagi di sela pekerjaan konten harian.

## Proses

1. **Menyusun brief** dan mengumpulkan referensi visual.
2. **Eksplorasi logo** dalam beberapa arah, lalu memilih satu arah untuk dikembangkan.
3. **Menetapkan sistem**: warna, tipografi, aturan jarak, dan cara memakai logo.
4. **Penerapan** ke feed media sosial, kartu nama, dan kemasan.
